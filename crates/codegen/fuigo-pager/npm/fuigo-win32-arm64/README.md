# @fuigo-official/fuigo-win32-arm64

Platform-specific binary for [`@fuigo-official/fuigo`](https://www.npmjs.com/package/@fuigo-official/fuigo) on win32-arm64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @fuigo-official/fuigo
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.

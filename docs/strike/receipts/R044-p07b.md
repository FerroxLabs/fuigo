## 1. Design

| Concern | Before | Now |
|---|---|---|
| Which tool row a tool hook belongs to | none shown (F045); the deleted machinery used "last tool row" | the shell stamps `tool_call_id` on `pre_tool_use` / `post_tool_use` / `post_tool_use_failure` batches (additive, `#[serde(default, skip_serializing_if)]`); the pager attaches by that ID only |
| Batches that arrive before their row | — | held per call (`orphan_tool_hooks`) and put on the row when it is created; dropped at turn end for calls that never get a row |
| Turn scope of IDs | — | the call→row map and held batches clear at every user message (any content, live or replayed) and at `finish_turn` |
| Rows created outside the tracker / rows that move | — | failing suppressed tools register through `finish_completed_tool`; fresh BgTask rows through `note_tool_row`; a removed background placeholder hands its runs to the replacement; Edit coalescing remaps a merged call to the surviving row (batches append) |
| Subagent hooks | dropped by the child route | live and replayed child `HookExecution` and `HookAnnotation` go to the child view |
| F045 | success silent, one line per non-blocking failure, deny left to the shell's annotation — all sources | unchanged for all sources |
| Plugin-origin runs (`plugin/...`) | silent | badge `[hooks: N]` on their call's row, or a lifecycle row for non-tool events; denies and skips are not badged; a plugin failure also keeps its F045 line |
| Long headers | badge appended past the row and clipped | the collapsed header is shortened (ellipsis) to reserve the badge's width |
| Plugins UI off | — | no hook rows, lines or badges (root and child) |
| Lifecycle rows | — | excluded from tool-usage statistics and from `/export`'s tool list |

Reused from `e89bbd1^` (via `strike/p07b-wip`): `blocks/tool/hook.rs`, `hook_tests.rs`, `lifecycle.rs`, `ScrollbackEntry::hook_data`
and its render, `attach_hooks`, verb-group hook counts, `entry_renderer`, the tracker/mouse/export/peek touch points. **Not**
reused: the stop-hook marker machinery and the hover popup (its byte-offset hit-testing was an audit finding).

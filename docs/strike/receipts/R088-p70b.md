## 2. User-visible behaviour changes (need Sean's yes), with release notes

1. **Error text shown to a client.** A credential Fuigo sent (8+ chars) that a provider or proxy echoes back reads
   `<redacted>` in the `session/prompt` error (`message`, `data.message`), retry / failure / turn-completed
   notifications, `fuigo/session/prompt_complete`, subagent failures, goal pause messages and `/btw` / recap errors.
   *Release note: API keys and other credentials that a model provider echoes back in an error are now shown as
   `<redacted>`.*
2. **What counts as "sent".** Every header value except the ones Fuigo composes itself, every URL query value, URL
   userinfo, and the credentials of a proxy set in `HTTP(S)_PROXY` / `ALL_PROXY`. So a configured non-secret value of
   8+ chars (an `api-version=2024-10-21` query value, an `anthropic-beta` header) also reads `<redacted>` when an error
   quotes it. *Release note: values Fuigo sends in request headers or the query string may appear as `<redacted>` in
   error messages, even when they are not secret.*
3. **Logs.** The same replacement in every log file (per-session debug logs, sampling / hooks / memory /
   instrumentation logs, `unified.jsonl`), the pager's log panel and stderr. A record that would still contain a
   credential after replacement is written as `<text withheld: it contained a credential>`. *Release note: log files
   no longer contain credentials echoed by a provider.*
4. **Telemetry.** OTLP, Sentry and Mixpanel scrubs apply the exact match before their existing patterns. *Release
   note: telemetry applies the same replacement.*
5. **Files and hook input.** `updates.jsonl` (the notifications above), subagent `meta.json`, `btw_history.jsonl`,
   `recap_requests/`, `compaction_requests/`, goal state, the uploaded `turn_result.json`, and `StopFailure` /
   `PostToolUseFailure` hook input carry the replaced text. *Release note: session files and hook input carry the
   replaced text too.*
6. **A parent agent sees a child's failure with the credential replaced** (the subagent error is scrubbed where it is
   built, so the tool result handed to the parent model says `<redacted>`). *Release note: a subagent failure reported
   to the parent agent no longer includes echoed credentials.*
7. **A cut-off credential.** Eight or more leading characters of a sent credential directly followed by `…` are
   replaced as well (error text is capped at 280 chars before display). *Release note: a credential truncated by an
   error-length cap is also replaced.*
8. **Pager decisions on scrubbed text** (open HIGH #2): if a sent credential overlaps one of the phrases the pager
   matches, the pager can pick a different message or miss a credit / re-auth prompt. *Release note: none proposed;
   this is the open item.*

Nothing changes when no sent credential occurs in the text: the scrub returns its input.

## 3. What changed

Classification is untouched: `SamplingError`, `SamplingErrorInfo` and every `acp::Error` inside the agent keep the text
as it arrived; the user-facing cap in `fuigo-sampling-types` is byte-for-byte the parent's (the crate only gains a test).

- **`fuigo-secrets/src/sent_credentials.rs` (new).** Process-wide registry. `record` (8-char floor, also the once- and
  twice-JSON-escaped spelling), `record_header_value` (whole value, token after the scheme, `;`/`,` parts outside
  quotes, `name=value` values, quoted strings with escapes resolved, `Basic` pair and halves), `record_proxy_url`,
  `record_transformed` (the respelling a rewrite gives a credential). `scrub` / `scrub_bytes` / `scrub_record` /
  `scrub_in_place` / `scrub_json_strings`: every occurrence, overlapping ones as one run, plus 8+ leading chars of a
  credential before `…`; postcondition: no recorded credential in the output (else `WITHHELD`, else empty).
  `ScrubWriter`. `safe_cut` / `truncate_chars` for text going into a log. Retention: nothing recorded in the last hour
  is forgotten; 256 older spellings; hard bound 4096. `redact_secrets` (telemetry chokepoint) runs the exact match first.
- **Recording (`fuigo-sampler`).** `sent_credentials.rs` `record_request`, called in `client.rs` `dispatch_request` and
  `subscription.rs` `dispatch`: every header value except a protocol constant under its own header
  (`STATIC_CLIENT_HEADERS`) and the names the client itself writes (`CLIENT_WRITTEN_HEADERS`); the configured values
  that are really on the request (`configured_header_values`, computed in `SamplingClient::new`); URL userinfo; every
  query value (raw, decoded, `+` as space); proxy credentials from the environment. Shell: the models-fetch bearers
  and the OIDC refresh token are recorded.
- **Log sinks.** `fuigo-telemetry` `appender::scrubbed_non_blocking` (every file log, with a source guard test),
  `unified_log::write_lines`; `fuigo-pager` `tracing.rs` channel writer; `fuigo-pager-bin` stderr writer.
  `body_preview` and the shell's unified-log previews cut with `truncate_chars`.
- **Display sinks (`fuigo-shell`).** `agent/credential_scrub.rs`: `ScrubSentCredentials` wraps the agent so every
  `acp::Error` reply has its human text scrubbed (`message`, bare-string `data`, `data.message`; discriminators
  untouched); `agent_side_connection` builds the connection on every transport (`server.rs`, `app.rs` x2,
  `leader/in_process.rs`, the test harness, the e2e testkit). `SessionUpdate::scrub_sent_credentials` (RetryState,
  AutoCompactFailed, AutoRecovery*, SubagentFinished.error, Memory*Completed.result, TurnCompleted.agent_result) at the
  top of both notification helpers, in `emit_subagent_notification` and in `handle_fuigo_session_notification`.
  `prompt_complete_fields`. The subagent error at its source (`prompt_turn_result.rs`). `StopFailure` hook payload.
  Goal pause message and goal evaluator error. `btw_history`, `recap_requests`, `compaction_requests`, laziness log,
  `turn_result.json`. `normalize_compact_detail` records the respelled credential instead of scrubbing (its output is
  classified afterwards).

## 9. Proposals

1. **P70c: typed verdicts on the wire.** The shell computes, from the unscrubbed text, the verdicts the pager needs
   (credit limit, free usage exhausted, re-auth, context length, recovered HTTP status) and sends them as typed fields on
   `RetryState` / error `data`; the pager decides on those and only displays the text. Closes #2.
2. **Carry the uncapped text to the normalizer** (or record prefixes when the 280-char cap cuts through a credential),
   so `normalize_compact_detail` can alias a cut credential. Closes R3-3.
3. **Proxy precision.** Record only the proxy reqwest will use for the request (scheme, `NO_PROXY`), ideally from the
   client builder rather than the environment.
4. **Structured log records.** Scrub JSON log records at the value level so a credential that is JSON syntax cannot
   break a record (#12).
5. **Other credentialed requests** (relay, storage upload, MCP HTTP, feedback) do not record what they send; their
   error text is only covered if the sampler happened to send the same credential.
6. **`fuigo-secrets` test isolation.** The registry is process-wide; tests in a crate that both record and assert share
   one lock per crate. A scoped registry for tests would be cleaner.

## Changes
1. **`crates/build/fuigo-proto-build/src/lib.rs`** — `emit_rerun_if_changed` printed `cargo:rerun-if-changed=protoc` when
   `find_protoc` returned the bare PATH name; cargo looks for `<package>/protoc`, never finds it, and treats the build
   script as stale on EVERY invocation, so `fuigo-tools-api` and everything above it rebuilt each time. New
   `protoc_rerun_path`: a path with a directory part (`$PROTOC`, `bin/protoc`) is kept as given; a bare name is resolved
   like `execvp` (PATH order, executable regular files only, empty entry = cwd) to an absolute path; unresolvable → no
   line. A PATH-resolved non-UTF-8 path is left untracked instead of failing the build. `PATH`/`PROTOC` are deliberately
   NOT rerun triggers (documented: different shells/IDEs/harness PATHs would reintroduce the spurious rebuilds; switching
   protoc needs `cargo clean -p <generating crate>`). 7 unit tests (`protoc_rerun_path_tests`).
2. **`crates/codegen/fuigo-pager-pty-harness/src/env.rs`** — port of P69: `pager_binary()`'s local fallback builds
   `cargo build --locked --message-format=json-render-diagnostics -p fuigo-pager-bin --bin fuigo-pager` once per process
   (`OnceLock<Result<PathBuf,String>>`, failure latched) and returns the executable named by cargo's single
   `compiler-artifact` message for bin `fuigo-pager` (zero / several / missing on disk → error). No guessed
   `<CARGO_TARGET_DIR>/debug` path. `PAGER_BINARY` and `CARGO_BIN_EXE_fuigo-pager` precedence unchanged. 5 unit tests
   (`env::local_binary_tests`, unix, fake cargo via `/bin/sh script`).
3. **`scripts/strike/final-gate.sh`** — `--network none` inner command is now
   `ip link set lo up && export CARGO_NET_OFFLINE=true && exec cargo test --offline …`, so nested cargo invocations
   (P69's per-process pager build) are offline by setting, not just by a warm cache. **Merge note:** one-line hunk on the
   `INNER=$(printf …)` line; P17-F3 (`strike/p17f3`, owner of gate scripts) has that line byte-identical (its line 240),
   so the hunk applies cleanly on either side.
4. **`.github/workflows/binary-driven-tests.yml`** (new) — job `binary-driven` on ubuntu-24.04: pinned protoc (same
   sha256 as the other workflows), rust-cache, `cargo build --locked -p fuigo-pager-bin --bin fuigo-pager`, then
   `cargo test --locked --no-fail-fast -p fuigo-shell --test '*_acp'`, `cargo test --locked --no-fail-fast -p fuigo-pager-bin --tests`,
   `cargo test --locked -p fuigo-test-support --lib env::local_binary_tests -- --include-ignored` (P69 freshness probe);
   logs uploaded as an artifact. Triggers: `push` (main, `release/**`), `pull_request`, `workflow_dispatch`; **no
   `paths:` filter** (a path-filtered workflow can never be a required check). `contents: read` only; no untrusted
   interpolation in `run:`.

## Round 3 (real) fixes
Astra r3 (real, on e2492a42) left 4 HIGH, 3 MEDIUM, 1 LOW. The path-prefix trust decision was replaced (code tip 992bcfd6).
Design: (1) trust is an exact allowlist of realpath'd, case-folded FILES: `$FUIGO_HOME/{config,managed_config,requirements}.toml`,
`/etc/fuigo/{same}`, `~/.claude.json`, `~/.cursor/mcp.json`, files under `$FUIGO_HOME/hooks/`; everything else is untrusted
(`worktrees/`, `plugins/`, aliases of them). (2) Provenance is a per-definition mark (`__fuigo_untrusted_source`, field
`McpServerConfig.untrusted_source`) set on every server an untrusted source defines, including inside `version_overrides`;
it travels through merge and override, and `to_acp_mcp_server` (the last point before a spawn) refuses key references in the
final strings. The process-global name registry and the spawn-name gate in fuigo-mcp are removed (fuigo-mcp is back at base).
(3) The env/headers exemption is by structure (`Ctx`), never by key name. (5) No extra JSON expansion pass.

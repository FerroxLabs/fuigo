## Root cause
`load_session` (fuigo-shell `agent/mvp_agent/session_setup.rs`) records the lost turn, then, for a no-replay load (headless
sends `noReplay: true`), forwards the interrupted-turn marker live and AWAITED the completion receiver, which resolves only when
the client has handled the notification. The headless `-p` client (`fuigo-pager/src/headless.rs::open_session`) handles
notifications only after its `session/load` request returns. Circular wait: no model request, no output, all threads parked, no
flock held (exactly A2's observation). 1.0.20 had no marker, so no wait. The second invocation found the turn already recorded
(no marker to forward) and worked. The B23 owner lock, `snapshot.lock` and rewind `rewrite.lock` are not involved.

Reproduced first on the shipped RC binary (`dist/fuigo-linux-x64-1.0.21.tgz`, 7c6c7886) with the e2e mock: run 1 killed by
the 30 s watchdog, run 2 0.44 s; the RC's log ends at `session.reconcile_stale_tasks` right after
"recorded it as interrupted" (log sha256 dc2754a2f79ffa3d6395c9138e05c755d8bb59b1ae866c0102e16a6df8639a84). Same script on the
fixed build: run 1 exit 0 in 0.70 s, the lost turn recorded `interrupted` (p143-live-fixed.log).

## Astra (gpt-6-astra, read-only; reports in docs/strike/audits/p143-astra-r{1,2,3}.txt)
- r1 (f4595ea3): NOT-LAND-OK. Root cause confirmed. HIGH stale-task reconciliation deadlock under noReplay (pre-existing, also
  1.0.20) -> fixed 67c5f4da; MEDIUM deferred reminder timing -> fixed e4df25da; MEDIUM test coverage -> a18e059a; LOW fixture
  child cleanup -> a18e059a.
- r2 (67c5f4da): NOT-LAND-OK. HIGH FIXED, LOW FIXED; deferred reminder MEDIUM NOT FIXED -> e4df25da + red test 5c7257a6.
- r3 (e4df25da): **LAND-OK**. All production findings FIXED; no BLOCKER/HIGH. Remaining MEDIUM (tests): the deferred test did
  not prove the request preceded the release -> fixed b1e5761c (asserted while held; M5 still killed). Not addressed: the process
  tests do not assert live-marker receipt by the client (headless ignores `turn_completed` by design; covered at ACP level by
  `fuigo-shell/tests/interrupted_turn_acp.rs` B). LOW accepted by Astra: if a deferred recovery's late append then fails, the model
  was already told and a later load may tell it again (before: a failed deferred append gave no reminder at all).
- No new production regression vs 71a99f8d or v1.0.20 in any round.

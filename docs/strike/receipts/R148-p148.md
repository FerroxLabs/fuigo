   no-operator reply instead of blocking for more than 400 s. The leader carries each client's initialize `startupHints` onto its session
   requests, and a resident session re-stamps the attach policy.
2. A key supplied through ACP `authenticate` resolves trusted `${FUIGO_API_KEY}` references in the same process.
   A saved or exported key still takes priority.

   notifications, so they produce no unsolicited RPC replies.
4. A folder-trust grant tells a session about a refused key reference exactly once. A sibling that is still announcing has the
   grant's refusals recorded into its open setup scope (Astra r3 MEDIUM).
5. Refusals in an agent definition's inline MCP or hooks reach the spawning session as a note and go to the log.

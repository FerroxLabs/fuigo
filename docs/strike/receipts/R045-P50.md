## Decision: (a) fix the key, do not delete
- `patch_initialize_response_model` (crates/codegen/fuigo-shell/src/leader/server.rs) read `/result/meta/...`. ACP wire key is `_meta`: agent-client-protocol-schema 0.11.4 agent.rs `#[serde(rename = "_meta")]` on InitializeResponse.meta.
- The agent emits `modelState` under that meta (agent/mvp_agent/acp_agent.rs initialize, `.meta(json!({... "modelState": init_model_state ...}))`); the pager reads it as typed `InitializeResponse.meta["modelState"]` (fuigo-pager/src/acp/mod.rs:609).
- Purpose (git log -S: only b5e43b9e, the 1.0.1 rebrand of Grok Build; doc comment): avoid the TUI briefly showing the agent's startup default model until the first session/new response. Plumbing is live: `patch_initialize_model` is set at server.rs ~1845 and consumed at ~1929. Only the key was wrong. The old unit tests hand-wrote `"meta"` JSON and so passed against the bug.
- So the patch guards real behavior that was broken: deletion (P00 author's recommendation) rejected.

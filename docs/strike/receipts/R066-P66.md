## Decisions
**1. `local-workspace`: removed (dead), not ported.**
- The feature's code calls `crate::gateway_bridge::{local_workspace_supervisor, ComputerSession, ..}` and
  `gateway_bridge_test_session_id`. Neither exists in this tree.
- Neither exists in `grok-build-upstream` (`bb7f39d "Synced from monorepo"`) either. Upstream carries the same cfg sites
  in xai-grok-shell, -pager and -pager-bin, but no `gateway_bridge` module. The module is monorepo-internal and was never
  published, so there is nothing to port.
- Nothing builds the feature:
  - there are no Bazel files in the tree;
  - `release.yml:214` is `cargo build --release ... -p fuigo-pager-bin` with default features (`jemalloc`, `sandbox-enforce`);
  - no workflow or script passes `--features` with `local-workspace` or `default-bazel`.
- The feature is gone from the `[features]` tables and `default-bazel` lists of fuigo-shell, fuigo-shell-base (an empty
  forwarder), fuigo-pager and fuigo-pager-bin.
- Every `cfg(feature = "local-workspace")` item was deleted as if the feature were off (scripted, every span reviewed):
  - 218 `cfg(feature)` and 25 `cfg(all(feature, unix))` sites, plus 1 `not(unix)` and 2 `all(test, ..)`;
  - `fuigo-pager/src/views/welcome/workspace_mode.rs`, reachable only under the feature, was deleted.
- The 8 `cfg(not(feature))` arms became unconditional.
- Constant leftovers were folded:
  - the always-`false` `session_local_workspace` param and its `qualify_permission_title_for_local_workspace`;
  - the unused `pub fn active_local_workspace` stub;
  - the unused `session_flags` param of `finalize_chat_session_meta`;
  - `bypass_chat_refusal = false` (×3), `workspace_picker_rows = 0`, `false && client_sent_kind_filter(..)`;
  - two `cfg_attr(not(..), allow(unused_variables))`.
- Comments that described the removed paths were corrected.

**2. config_docs: the test reads the real page.**
- `crates/codegen/fuigo-shell/AGENTS.md` is not in upstream, not in this tree's history (`git log --all` is empty), and
  no `AGENTS.md` anywhere carries the "Edit it; do not regenerate it." text. It was never shippable here.
- `page_is_the_user_facing_field_list` now checks the shipped `fuigo-pager/docs/user-guide/26-config-reference.md` itself:
  - the opening "complete field list" claim;
  - the three `## config.toml` / `## managed_config.toml` / `## requirements.toml` sections;
  - that both tables parse to rows;
  - the existing header-row, `models.allowed_models`, `### cli` and no-registry-leak asserts.
- The contributor "edit that file" guidance already lives in the module doc comment.

**3. `worktree-lifecycle-bench`: removed (dead).**
- It needs `grove::paths::GroveDirs`, `grove_git::{hermetic_git_command, redact_git_text, DEFAULT_GIT_DEADLINE}`.
- Those are upstream-internal crates, absent upstream and here, with no equivalent in this tree. Shimming them would
  invent their semantics.
- No script, workflow or doc references the bin.
- Removed:
  - the `[[bin]]` entry and the `lifecycle-bench` feature;
  - the bin sources (`worktree_lifecycle_bench.rs` and its directory);
  - the optional deps `sha2`/`url`/`uuid`, which only that feature enabled.
- **Cargo.lock is touched:** three lines (`"sha2 0.10.9"`, `"url"`, `"uuid"`) leave fuigo-fast-worktree's
  `dependencies` list. This is required, because `--locked` builds fail otherwise. No package entry changes; other crates
  still use all three. This is P11's seam: the edit is confined to that one stanza.

**4. Voice gate: per-thread pin.**
- `voice_mode_enabled()` reads a `cfg(test)` thread-local override first.
- `pin_voice_mode_for_test(on)` returns a `!Send` guard (`PhantomData<Rc<()>>`) that restores the previous override on
  drop; `.set()` flips it in place.
- Both settings_modal voice tests (`rebuild_rows_drops_voice_settings_when_gate_turns_off`,
  `rows_contain_categories_and_settings_through_pr_14`) use it and no longer write the process global.
- Concurrent `apply_voice_mode_enabled` writers can no longer flip their view mid-test.
- New test: `voice_mode_pin_shadows_the_global_gate_and_restores`.

## Proposals (outside P66 ownership)
1. **fuigo-fast-worktree `nfs-create-latency-bench` on macOS** uses `grove_git::hermetic_git_command` inside its
   `cfg(target_os = "macos")` module. It cannot build on a Mac (the Linux stub compiles). Same root cause as item 3:
   either remove the mac arm or the bin.
2. **fuigo-pager-render `util::tests::display_fuigo_home_prefix_default_install`** failed at parent in the matrix
   (`"$FUIGO_HOME"` vs `"~/.fuigo"`), and in `p63rp`. It reads a process env var that concurrent tests set, so it needs
   an env guard or serialization.
3. **Other process-global gates in fuigo-pager tests** (`MINIMAL_MODE_ACTIVE`, `VOICE_KEYBIND_ENABLED`,
   `KITTY_RELEASES`) follow the same save/flip/restore pattern that made the voice test flaky. The
   `pin_voice_mode_for_test` pattern applies to them.
4. **Gate scripts:** pass `CARGO_INCREMENTAL=0` by default. The incremental cache was 75 G of this lane's 167 G target.
5. **fuigo-workspace `test-support` set** has 4-7 failures at the parent (permission-manager `auto_*` and envrc tests). That
   needs its own packet before the final gate runs features on fuigo-workspace.

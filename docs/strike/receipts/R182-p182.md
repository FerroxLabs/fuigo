## What changed
- **Item 1 (MEDIUM).** A login directory outside the fuigo home now gets its own `AuthDirWatch`. If the directory cannot be watched
  (missing), a helper thread retries on a doubling backoff (1 s, 2, 4, 8, 16, capped 30 s; no tight polling). On attach it sends
  `AuthChanged` if the login file already exists (covers a write between creation and attach). Dropping the watcher stops the thread.
- **Item 2 (LOW).** That watcher forwards only events for the login file (`is_auth_event`); other files in the directory (`config.toml`,
  `.mcp.json`, `.claude.json`, `models_cache.json`, siblings) are dropped. The directory is skipped when it equals the fuigo home (`paths_equal`),
  so home behaviour is unchanged.
- **Item 3 (LOW).** `trust.rs`: `p182_read_swapped_for_dangling_link_after_probe_is_an_error_not_missing_windows`, `#[cfg(windows)]`. It skips
  (with a message) when the OS refuses symlink creation (`PermissionDenied` or raw 1314). **Hetzner cannot run Windows: it was never compiled
  or run; only Astra's inspection says it compiles.**

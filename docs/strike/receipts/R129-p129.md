# R129: P129, a client newer than the installed version no longer evicts the installed-version leader (P124 residue a3)

Parent `7db4a770`, branch `strike/p129`, code tip `bf904275` (this receipt is the only later commit). Lanes `p129a`, `p129b` (target dirs deleted).

## Change
`evict_decision` skips eviction when the leader's version EQUALS the installed version and that is lower than the client's own: the client is the stale binary and a respawn would run the leader's own version. The client connects to that leader without killing it and prints a notice (once) naming both versions and the managed executable path. Installed version = target name of `<fuigo_home>/bin/fuigo`, only for a managed client (current_exe under fuigo_home, the same condition under which `resolve_binary_impl` spawns through that symlink); dangling, missing, unparseable or non-managed gives `None` and the P124 behaviour. The name parser moved to `fuigo_shell::leader::version_from_versioned_binary_name`; `fuigo-update` delegates, so there is one parser. Choice justified: connect (not refuse), because refusing would stop a newer binary from running at all, and P124 already adopts a lower leader after a spawn.

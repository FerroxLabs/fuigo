## P187: `FUIGO_ALLOW_UPSTREAM_HOSTS` accepts an exact-host list
`fuigo-extra-ca` (`egress.rs`, `redirect.rs`, `dispatch.rs`, `public_download.rs`) and the `/provider` warning
(`fuigo-pager/src/slash/commands/provider.rs`). The variable used to be a process-wide switch. It now also takes a
comma list of exact hosts (for example `api.x.ai`) and lifts the vendor-host refusal for those hosts only.
Matching is exact after ASCII lower-casing and removal of one trailing dot. Empty entries, wildcards, ports,
userinfo, schemes, non-ASCII hosts and `1` mixed into a list make the whole list invalid, which fails closed.
`1`, `true`, `yes`, `on` (any case) still mean the full lift; the lower-case forms were accepted before P187.
This is an exception list for the vendor denylist, not a general network allowlist.

## The P174 slowdown (found by this landing's re-proof)
`s1-p174` at `b70d2b06a`: fuigo-shell 3 failures at the tip, 0 at the parent, all
`prepare_tool_call must not hang: Elapsed(())` (5 s, `acp_session_tests/support.rs`):
`permission_prompt_notification_tests::auto_allowed_tool_does_not_fire_permission_prompt_notification`,
`pre_tool_use_decision_tests::pre_tool_use_ask_with_non_object_rewrite_still_forces_one_prompt`,
`pre_tool_use_decision_tests::pre_tool_use_updated_input_rewrites_prepared_call`.
Isolation (`s1-p174iso`, 3x `--exact` per side): 0.03-0.04 s each at `b4ca54a50`, 1.3-1.7 s each at `b70d2b06a`,
every run. Not a flake.

Cause: `SessionActor::judged_read_files` (`read_dedupe_hook.rs`) called `resolve_read_target` for every
`read_file` call, with or without a policy. For a path that does not exist that falls into
`try_resolve_unicode_filename` (`fuigo-tools/src/util/fs.rs`), a `read_dir` of the whole parent directory, on the
session actor path. The tests read a missing file in `/tmp`, which held about 517,000 entries on the build box.
Production: only reads of a missing file, cost proportional to the size of its directory.

Fix `2b55783b8` (red `c0503555a`): `resolve_existing_read_target` (no Unicode fallback) in `judged_read_files`;
a missing file is not de-duplicated. The permission manager's resolver (`read_target_spellings`,
`evaluate_read_targets`) is unchanged: with a policy, every spelling of every read target is still judged,
including the reader's Unicode fallback (`deny_follows_the_readers_unicode_fallback`). After the fix the three
tests take 0.02-0.04 s (3 runs each). Regression test
`judged_read_files_does_not_scan_the_directory_for_a_missing_file` fails by assertion at the red commit.

The intermediate commits `b70d2b06a..a348c15f2` carry the slowdown; the landed tip does not.

## 1. Read first: decisions for Sean (each with a verified recommendation)

1. **Workspace environment uploads carry `user_id` and the team `principal_id`.** This is
   `fuigo-workspace/src/upload/environment.rs:24,104,175`, enqueued for the storage proxy at `fuigo-workspace/src/handle.rs:2612`
   with no identity decision. It is outside P54's ownership.
   **Recommendation:** gate it in its own packet with the P54 helper: `body_identity` on the storage-proxy URL, so the
   fields are omitted unless the proxy is FluxRouter. Collection consent alone does not make a non-FluxRouter proxy a
   destination the user configured for this data.
2. **Identity in local logs that ride trace uploads.** `unified_log` and debug-log entries carry `user_id`, for example
   `agent/subscription_check.rs:103-169`, `agent/mvp_agent/mod.rs:1790-2710` and `auth/manager.rs:1928`. They are
   uploaded through `upload/trace.rs:845` (auth diagnostics). Persisted feedback submissions in `feedback.jsonl` carry
   `author_email` inside session archives (`session/feedback_manager.rs:99`).
   **Recommendation:** add one archive-time filter, built like `withhold_loc_identity`, for every file packed into an
   archive bound for a non-FluxRouter proxy, in a follow-up packet that owns `upload/`.
3. **Behaviour change, accepted by the charter.** An operator-configured registry, session backend, storage proxy or
   internal OTLP collector that is not `https://api.fluxrouter.ai` now gets the following:
   - a pseudonymous `deviceId` and `agentId`, stable per origin;
   - no `hostname`;
   - no account, team, org, deployment or api-key ids in OTLP resources or span attributes;
   - review comments without `agentId`.

   Mixpanel never receives identity, and its `distinct_id` is a pseudonym for the Mixpanel origin. Any analytics keyed
   on the raw account id there will split once, at upgrade.
   **Recommendation:** accept. This is the P43 policy applied to bodies. Fuigo ships every auxiliary base empty, so a
   default install is unaffected.
4. **External OTEL, product events, `[feedback.user]` author and ACP initialize are unchanged** (§3). Each one is either
   configured by the user for exactly this data or not a network destination.
   **Recommendation:** keep them.

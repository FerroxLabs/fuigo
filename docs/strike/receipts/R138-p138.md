## Release-note text
Changed line (S), appended to P133/P136's saved-key line: "A client-supplied MCP server that carries the saved key's value itself (not only a reference to it) loses it too."
Changed line (B), MCP hot reload: "After you edit or delete an MCP server in your config, a session's next reload uses what is on disk: the old copy your editor forwarded no longer
outlives a delete or masks an edit, and no longer logs a refusal for it on every reload."
Changed line (B), folder trust: "Refusals of a reference to the saved key in a project's MCP servers are now shown in the session when you trust the folder, not only logged."
Not user-visible (internal, no release-note line): a pager without a credential resolver no longer logs a "differs from the user's own definition" warning for a
server that reads the saved key by name; failed `session/new` calls no longer pile up notice scopes. K row: the P136 known limit "hot reload is logged only" shrinks
to "config and plugin hot reload are logged only"; the folder-trust grant is no longer in it. The P136 note "(c-3) a deleted server keeps running until restart" disappears.

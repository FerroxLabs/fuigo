## How the class is recognised
`StrictFail { detail, typed_pins }` (validation.rs) is returned by `strict_admin_toml` / `strict_managed_settings`; `typed_pins` is true only after a complete read and parse where the sole failure is wrong-typed keys (bad `[[version_overrides]]` beside it, or a non-object JSON root, set it false). No text matching. `admin_source_state` -> `AdminSource::{Text, Locked, Broken}` carries the decision; `Locked` only when a copy exists. The read-failure paths (`read_requirements_source`: blank-unstable, symlink, owner/mode, UTF-8) never reach the classification, so they keep the copy.
## Once and lifting
`announced_lockdowns` (path -> hash of the broken text): one `tracing::error` per broken version (file and keys named). `remember_admin_source` / `forget_admin_source` (every valid accept or stable blank) clear the entry, so lifting is simply the next read being valid (that text becomes the copy, as before) and a later break is a new episode. A different broken text announces again.

## Session message (condition 1): findings (step 1; wiring NOT built, awaiting a design choice)
(a) Fresh start. `validate_requirements_or_exit` (`fuigo-pager-bin/src/main.rs:2113`) prints to stderr before the TUI: `Couldn't start Fuigo: <RequirementsError>` plus "Update Fuigo to a version the policy allows, or ask your administrator to fix the managed requirements." and exits 2. (b) Running session. There is NO reload path for admin policy. `config/watcher.rs` watches only fuigo home, auth, cwd and discovery dirs (no `/etc/fuigo`, no managed_config, no managed-settings.json); `config/reloader.rs` has no admin variant. The only surface now is the P186c `tracing::error`.
Options: (1, recommended) a small per-session poll: at turn start (or on a watcher event for the admin files) the session calls a new `fuigo_config::admin_lockdown_transition()` that returns Entered(file, keys)/Still/Lifted(file) from the existing once-per-version key (no second once-mechanism) and sends one `ConfigNotice` via `NotifyConfigNotice`; the text is the Unloadable wording minus "refusing to start", through `untrusted`. (2) add `/etc/fuigo`, `managed-settings.json` to the watcher and reloader (bigger: new watch roots, inotify on root-owned dirs). (3) accept the log line only and amend the owner condition.

## What changed
- **Item 1.** `ConfigReloader::auth_path()` = `auth::auth_json_path(home)` (the P167 resolver); used by `reload_auth` and
  its error log. `ConfigFileWatcher::start` resolves the same path, watches its directory non-recursively when it is not
  the home, and classifies an event as `AuthChanged` iff it is that exact file (`is_auth_event`: equal path, or same file
  name with an equal canonical parent). `<home>/auth.json` no longer fires when the login lives elsewhere. The two
  initial key hashes in `agent/app.rs` use the resolver too.
- **Item 2** (behaviour-preserving extractions so the behaviour can be tested through the real call path):
  - (a) stderr prompt: `agent/folder_trust.rs::stderr_prompt_decision(accepted, persist)`; test
    `p180_stderr_prompt_fails_closed_when_nothing_was_saved`.
  - (b) GUI prompt: `mvp_agent/folder_trust_prompt.rs::settle_gui_grant(...)` (notice to every covered session when not
    saved; Unrecorded releases the dedup key and stops); test `p180_gui_prompt_sends_a_notice_when_a_grant_is_not_saved`.
  - (c) trust store: test-only `AFTER_PROBE` seam in `trust.rs::read_doc_strict`; tests
    `p180_read_swapped_for_dangling_link_after_probe_is_an_error_not_missing` (unix) and
    `p180_read_removed_after_probe_is_missing`.
  No pre-existing test covered (a), (b) or (c) discriminatingly (Astra P167 r3 LOW #4).

## Known limits (recorded, not fixed)
1. **MEDIUM (Astra r1, accepted).** If the custom auth directory does not exist at startup, its watch fails and is not
   retried; a login that later creates the directory is not reloaded live until restart. The default home has the same
   property (the watcher refuses to start without it). Packet proposal: re-arm the auth-directory watch when an ancestor
   reports the directory's creation.
2. **LOW.** Non-auth files in an auth-only directory (e.g. a `config.toml` beside `/srv/secrets/login.json`) take the
   generic arms. Proposal: drop events in an auth-only dir that are not the auth file (needs a shared set of dirs watched for other purposes).
3. **LOW.** No Windows variant of the dangling-link swap test; none of this ran on macOS or Windows.

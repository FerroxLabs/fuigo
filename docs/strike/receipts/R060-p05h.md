## 3. Fix

- `crates/codegen/fuigo-tty-utils/src/best_effort_stdout.rs` (new): `write_all_bytes`/`flush_retrying` (Interrupted
  retried; WouldBlock retried 25 × 10 ms), `write_bytes`/`write_fmt`/`write_line` (writer-parameterised),
  `print_bytes`/`print_fmt` on the locked process stdout, `Outcome {Written, ReaderGone, Failed}`, process flags
  `reader_gone()` (BrokenPipe: dropped silently) and `hard_failure()` (anything else: one stderr note), macros
  `cli_println!` / `cli_print!` (type `()`).
- `fuigo-pager`: all 113 CLI `println!`/`print!` sites → the macros (`models.rs`, `plugin_cmd.rs`, `mcp_cmd.rs`,
  `sessions_cmd.rs`, `memory_cmd.rs`, `trace_cmd.rs`, `worktree_cmd/mod.rs`, `completions_cmd.rs`,
  `app/session_startup.rs::emit_pre_tui_restore_line`); `completions_cmd::run` generates every shell into memory
  (clap_complete `expect`s on its writer) then prints best-effort; `models::list_available_models` returns after the
  auth line when `reader_gone()` (no agent started for nobody); `src/best_effort_stdout.rs` re-exports the helper and
  pins the sources.
- `fuigo-pager-bin/src/main.rs`: 18 sites → macros; `STDOUT_FAILURE_EXIT_CODE = 1`, `stdout_exit_code()`: the
  `Ok(Finished)` arm drops the Sentry guard then exits 1 on `hard_failure()` (same order as the `Err` arm); the
  pre-runtime dispatches (`--version`, `doctor`, subscription commands) check it on their early return; the legacy
  `login`/`logout` paths pass it to `finalize_and_exit`. A gone reader stays exit 0.
- `fuigo-shell/src/auth/subscription/{mod,inference}.rs`: 3 sites → macros; `fuigo-shell/src/mcp_doctor.rs`
  (`fuigo mcp doctor` report): 16 sites → macros (found by Astra's diff audit, round 3).
- Remaining raw `println!` in the three crates are test-only (`session/result.rs`, `tool_dispatch.rs`,
  `leader/mod.rs` (windows test), `agent/key_discovery.rs`), verified by reading each site.

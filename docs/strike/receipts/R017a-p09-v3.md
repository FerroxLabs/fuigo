## 2. Residual risks (replacing R017 §2's list)

- **Mixed versions.** A pre-lock Fuigo running the same session holds no lock (unchanged from R017).
- **A hung holder.** A process that is alive but hung while holding the exclusive recovery lock (for example,
  stopped under a debugger) stalls the spawn of *that one session's* actor elsewhere until it releases. This
  is an async wait with a warning after 5 s; other sessions and the connection keep running. A live
  recoverer releases within `RECOVERY_APPEND_TIMEOUT` plus local I/O. *(Superseded by P09-F, R020 §F2: after
  60 s the load fails with a retry error instead of waiting forever.)*
- **N6** as above.

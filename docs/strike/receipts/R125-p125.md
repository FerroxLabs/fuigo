# R125 - P125: relay sync opt-in, and the leader's relay refusal shown in the TUI

Branch `strike/p125` on `strike/integration` 9381f19c. Items from R100 proposals 1 and 2 (K3).

## 1. What changed

1. **Relay sync is gated by the relay opt-in** (`RelaySync::new`, `relay/sync.rs`, via `relay_sync_gate` in
   `agent/relay_opt_in.rs`). A relay FluxRouter does not operate gets a session only if its origin is in `[relay]
   trusted_origins` (user config) or `FUIGO_TRUSTED_RELAY_ORIGINS`. Refused: no task, no socket, no byte. No caller can bypass:
   the gate is inside the constructor (now returns `Result`).
2. **Refusals are shown in the TUI.**
   - TUI session sync refused: `create_relay_sync` sends `fuigo/relay/refused` (origin, `use: sync`, full text, `sessionId`).
   - Leader refused its bridge: `bridge_permitted` publishes on a `RelayRefusalBoard` (`LeaderServerControlState`); the IPC
     server sends the `_fuigo/relay/refused` line to interactive clients on registration and when it changes, and
     `_fuigo/relay/refusal_cleared` when the user opts in. Clients that set the new capability `relay_refusal_state`
     (the TUI) are told the state on every registration, so a reconnect reconciles.
   - Pager: text says which relay, why (FluxRouter does not operate it; what the relay would get), and how to trust it
     (`trusted_origins = [...]`, env var). Shown in the session scrollback once per session, plus a toast; never into a
     running turn or streaming wake (deferred, shown by the tick); sync refusals are session-scoped; the leader's notice is
     cleared on `refusal_cleared` and on reconnect.
3. Docs: destination-trust-policy and the config reference now say sync is gated.

## 2. Release-note text

F/B/S line: *"TUI session sharing (`[relay] enabled`) now only syncs to FluxRouter's relay or to a relay whose origin you
list under `[relay] trusted_origins` (or `FUIGO_TRUSTED_RELAY_ORIGINS`); otherwise the session is not synced and the TUI
says which relay, why, and how to trust it. When the leader refuses an untrusted relay, the TUI shows the same message."*
The K row for "relay sync not gated" and the K row for "leader refusal only in the log" disappear.
Behaviour change: users who already synced to a non-FluxRouter relay must add the opt-in.

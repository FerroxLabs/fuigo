## Root causes
1. Unpinned theme writers: tests wrote the process-global theme without the shared lock (bg_task, text_selection; P68 pinned those two and 15 user.rs tests, this branch took P68's versions). About 400 further `#[test]`s read the theme without the pin; they now hold `pin_theme()`. A source-scanning guard (`theme_pin_guard_tests.rs`) fails on any new unpinned theme mutator in the three pager crates' test code, and on a dashboard-opening test lacking `serial(FUIGO_AGENT_DASHBOARD)`.
2. Theme cache races (product code, `fuigo-pager-render/src/theme/cache.rs`), one design: `KindCell` (value, loaded flag, publish lock). (a) The lazy seed read disk unlocked then stored unconditionally and could overwrite a concurrent `set`; now it re-checks `loaded` under the publish lock. (b) `reset_for_test` left LOADED false under the test lock, so an unlocked reader could seed from the test home's config over a pinned theme (P68's finding); now reset calls `set` and leaves the cell loaded. Deterministic tests on private cells: lazy_seed_does_not_overwrite_a_set_that_landed_during_the_disk_read, a_second_seeder_does_not_overwrite_the_first, lazy_seed_publishes_the_disk_value_when_unraced, set_flips_loaded_so_a_later_read_skips_the_disk_reseed; one global test reset_for_test_leaves_the_cache_loaded_so_an_unlocked_reader_cannot_reseed.
3. double_submit_prunes_pending_after_latest: a timing bug, not a theme race. Instrumented parent run (diag-parent-failure.lines): the worker's first-use syntect compute took 1982-2078 ms under load and the test's 2 s wall-clock deadline expired (the TIMEOUT line precedes the compute completions). Fix: `edit_hl_wait_settled_for_test` blocks on the worker's channel, no deadline; the poll was split into drain + `apply_edit_hl_results` (behaviour unchanged); the test also pins the theme and asserts the entry left Pending.
4. execute_header_display_matches_overlay_body: two renders through the global theme with no pin; now pinned. Mechanism test bash_display_rows_are_styled_from_the_global_theme.
5. Found while measuring (parent flakes): the six dashboard-opening tests lacking the serial key (dashboard_enabled reads env FUIGO_AGENT_DASHBOARD, set to 0 by siblings); and visual_selectable_cols_shifts_region_past_rtl_ellipsis read the bidi latch outside its lock. Both fixed.

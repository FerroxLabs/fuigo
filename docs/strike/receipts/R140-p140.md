## What is NOT met / limits
- **Older Fuigo does not take the new lock.** A rewrite by a Fuigo older than P140 still holds only the shared append lock, so
  it can still race a rewrite by a newer one (and two older ones race each other as before). Both rewriters must run P140+.
- If the rewrite lock file cannot be opened or locked at all (read-only directory, directory in its place) the rewrite goes on
  without it, exactly as it already did for the append lock; exclusion is then not guaranteed.
- Unix lock behaviour tested on Linux only; Windows and macOS untested. The owner-only mode test is Unix-only.
- The "damaged rows byte for byte" guarantee is unchanged from P114: the reader trims surrounding ASCII whitespace of a row
  and the encoder adds the newline (Astra r1 note, pre-existing).

## Design
Second lock file `rewind_points.jsonl.rewrite.lock`, created owner-only through `owner_only::open` (P120). Every rewriter
(`rewrite_rewind_points`, used by `truncate_rewind_points_from` and `merge_rewind_points_from`) takes it EXCLUSIVE, then the
existing SHARED append lock, under one absolute 10 s deadline (`lock_bounded`); both are held from the read to the rename.
Timeout fails the rewrite with `WouldBlock` before anything is read, file untouched (same retryable behaviour as before).
Appenders and readers (including the workspace `file_state` read lock) never take the rewrite lock, so they are neither
blocked by it nor reorder against it; lock order is always rewrite then append, no path takes them the other way round. The
append-lock semantics (appends excluded, readers allowed) and every P114/P123/P135 guarantee are unchanged.

## Release-note text
- B-line: two Fuigo processes rewinding the same session at the same moment no longer lose one rewind-history edit; the second
  waits (up to 10 s, then the rewind is retried) for the first. The new lock file `rewind_points.jsonl.rewrite.lock` is
  owner-only.
- K19 shrinks to: a rewrite by a Fuigo older than this version does not take the new lock and can still race a newer one;
  when the lock file cannot be opened the rewrite proceeds without exclusion.

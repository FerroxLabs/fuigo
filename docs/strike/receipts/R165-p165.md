## Release-note text (for docs/release-notes-1.0.22.md)
- S: Tools with side effects outside files, shell and web — `scheduler_create`, `scheduler_delete`, `workflow` (except a
  `validate_only` dry run), `image_gen`, `image_edit`, `image_to_video`, `reference_to_video` — no longer run without asking.
  1.0.21 classified them, and any tool it did not list, as reads, which are approved automatically. They now prompt for each call
  (allow once / reject), follow always-approve, auto mode and `prompt_policy` like other prompts, are refused under `fuigo -p`
  without `--always-approve` (exit 3), and a tool-wide `Edit` deny or ask rule (`Edit`, `Edit(*)`, `Write`) also covers them.
  Pre-approve one by name with a bare rule, e.g. `[permission] allow = ["scheduler_create"]`.
- S: codex `read_file`/`list_dir`/`grep_files`, `memory_get` and the LSP tool now pass their path to Read rules (a `Read(...)` deny
  or ask applied to `read_file` but not to them).

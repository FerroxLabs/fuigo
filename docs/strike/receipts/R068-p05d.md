## 1. P2 (priority) — no `RefCell` borrow spans an await in the session actor

### Finding
`crates/codegen/fuigo-shell/src/session/acp_session.rs:1` carried a file-header
`#![allow(clippy::await_holding_refcell_ref)]` covering the whole actor tree (`acp_session_impl/*` and
`compaction.rs`, both included by `#[path]`). Removing it and running `cargo clippy -p fuigo-shell --lib` at the
parent listed **36** `RefCell` references held across an await (`clippy-shell-lib.log`, 2026-10-02T03:58Z):
34 in the actor tree (`compaction.rs` ×3, `turn.rs` ×2, `spawn.rs` ×6, `cancel.rs` ×5, `run_loop.rs` ×5,
`turn_task.rs` ×2, `session_mode.rs` ×3, `mcp.rs` ×2, `session_setup.rs`, `turn_end.rs`, `goal_support.rs`,
`notification_drain.rs`, `prompt_queue.rs`, `slash_exec.rs`) and 2 pre-existing warnings in
`agent/mvp_agent/session_setup.rs` (525, 899). The three `compaction.rs` sites P05 called C2 (1341–1375, 1579–1620
at R060's parent) were the ones a manual `/compact` task can park on the toolset lock while a zero-turn `/model`
harness rebuild runs `*self.agent.borrow_mut() = new_agent` inline (`run_loop.rs:1114` spawns compaction;
`model_switch.rs:244` writes).

### Fix
- `compaction.rs`: `tool_names_by_kind(first, second)` takes the bridge handle (`tool_bridge_handle()`, the existing
  accessor whose doc says exactly why) before `render_prompt(...).await`; the three `${{ tools.by_kind.* }}` pairs,
  `agents_md_reminded_paths`, `list_background_tasks`, `tool_for_kind(Workflow)`, `on_agents_md_compaction`,
  `on_skill_discovery_compaction` all go through the handle.
- Same shape at every other `self.agent.borrow().tool_bridge().…await` site (31 sites in the files above).
- `turn.rs:1899`: `completion_requirement().cloned()` inside one borrow instead of a `Ref<Agent>` held across whole
  turns (`CompletionRequirement: Clone`).
- `session_mode.rs:132`: dropped the call to `Agent::update_policies_from_definition`, a documented no-op whose only
  effect was a `Ref` across an await. `session_mode.rs:139`: `prompt_context_for_definition(def)` + a bridge clone in
  one short borrow, then `ctx.render(&bridge).await`.
- `fuigo-agent/src/agent.rs`: new sync `Agent::prompt_context_for_definition`; `render_prompt_for_definition` is now
  that plus `render`, so the two cannot drift.
- `prompt_queue.rs:215`, `run_loop.rs:84`, `slash_exec.rs:724`: bind the clone (`trace_config_template`,
  `hook_registry`, `memory.storage()`) before the `if let` whose body awaits.
- `agent/mvp_agent/session_setup.rs` 525/899: `title_policy` read into a local before the `persistence::new(...)` /
  `load_light(...)` call whose argument list held `cfg.borrow()` across `.await`.
- The file-header allow is gone; `await_holding_refcell_ref` (warn-by-default, `clippy::suspicious`) now runs over
  the actor tree. Hits after the sweep (`cargo clippy --locked --all-targets -p fuigo-shell -p fuigo-agent -p fuigo-pager -p fuigo-pager-bin`): **0** at `ace8ecbf` (`clippy-sweep2.log`, 0 errors, 48 warnings vs 58 one commit earlier when ten test fixtures still held `Ref`s); the final tip is re-checked by the gate's clippy leg below. Ten of the 36 were in `acp_session_tests/*` fixtures (`support.rs` ×2, `parallel_dispatch_tests.rs` ×2, `plan_exit_batch_barrier_tests.rs` ×2, `interjection_actor_tests.rs` ×2, `auto_wake_suppression_tests.rs`, `turn_completion_emit_tests.rs`) and take the handle too.

### Test (deterministic interleaving)
`session/acp_session_tests/compaction_agent_borrow_tests.rs`, mounted from `acp_session.rs`:
`a_rebuild_can_take_the_agent_while_compaction_waits_on_the_toolset` builds the test actor
(`create_test_actor_ex`), locks the toolset's `resources` (the tokio mutex `ToolBridge::render_prompt` awaits),
pins `tool_names_by_kind` and polls it by hand with a no-op waker until it is `Pending` on that lock (no scheduler
involved, so the suspension point is exact; the first version used `spawn_local` + `yield_now`, replaced on Astra's
note that Tokio does not guarantee scheduling order), then takes `actor.agent.try_borrow_mut()` — the rebuild's
write — and requires `Ok`, then releases the lock and awaits the helper. A control test checks the helper returns
when the toolset is free.

## 9. Proposals (outside this packet)
- P5 `fuigo-agent` `prompt::skills::discovery_budget_tests::an_overrun_scan_still_populates_the_cache_for_the_next_session` waits a fixed 1200 ms for a 600 ms overrun scan to land; under a loaded gate host it rescans (observed once here, 6/6 clean in isolation).   `await_holding_refcell_ref` tolerance the same way once their borrow-across-await sites are inventoried.

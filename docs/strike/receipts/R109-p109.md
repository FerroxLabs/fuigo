**Finding P109-F1 (pre-existing): the v1.0.7 to v1.0.11 releases never served this installer.** They carry only the
seven npm tarballs, `release-manifest.json` and `SHA256SUMS` (`gh release view v1.0.11 --json assets`). Read-only
probe: `gh release download v1.0.11 --repo FerroxLabs/fuigo --pattern fuigo-1.0.11-macos-aarch64` prints
`no assets match the file pattern`, exit 1. So "match the existing format" alone would not fix P106-F3. Fix without
touching clients: the release carries the v1.0.11 set **plus** six raw binaries under the installer's names.

## Release-note text
- B26: a session whose saved history was cut by a crash is repaired when opened, and also when a subagent resumes it or
  it is forked; the repair note is shown once and is no longer replayed each time the session loads. While the backup of
  the history file cannot be made, a refused compaction no longer sends a memory-save request first, an automatic
  compaction shows its failure note once, and a mode or model switch, a goal or memory change, a client system prompt
  override or an image strip says that the saved history was not rewritten and why.
- B30: a fork copies one snapshot of its source: a prompt added while the fork is made is in both the fork's transcript
  and its model history, or in neither.
- A damaged entry in a session's saved file versions no longer fails export or the writeback backfill, and a rewind that
  rewrites the file versions no longer loses an entry another Fuigo process saves at the same moment.
- K14 shrinks to: no hard links or advisory locks (the repair stays in memory); the backup is made once; an older client
  does not show the repair note; with the backup still blocked, a later open repairs in memory again and says so.
- K17 shrinks to: a prompt is in both or neither unless the source is rewound at that moment, a writer that does not use
  the new lock (an older Fuigo) is active, or the lock is stuck for over 10 s; text streamed within one turn is not covered.

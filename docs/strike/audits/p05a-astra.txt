   An alive PID with an unavailable start token becomes eligible after 30 days. The reader then renames and deletes its slot, so that session’s eventual crash writes into an unlinked file. The legacy branch similarly deletes an empty slot after seven days without proving its owner dead. **Fix:** always preserve `AliveUnverified`; age must never substitute for proof of death. 2. **HIGH — Reinstalling after `fork()` deletes the parent’s slot.** [handler.rs:598](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/handler.rs:598)  
   A child inherits `SLOT_PATH`. Calling `install()` creates its own slot, overwrites `OWNER_PID`, then unconditionally removes the inherited previous path. The parent remains alive with an unlinked crash FD. The fork test exercises crash/exit only, missing this case. **Fix:** retain the previous owner identity and unlink previous slots only when owned by the current PID; test parent install → fork → child install → parent crash.

3. **MEDIUM — Crash evidence is discarded before a report is successfully saved.** [lib.rs:281](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/lib.rs:281), [lib.rs:320](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/lib.rs:320)  
   Read errors become empty data, and the claim is deleted before symbolication or report writing. An interrupted reader, unreadable blob, or failed report write permanently loses the evidence. Ignored write errors also let the notice advertise a nonexistent report. **Fix:** propagate errors, retain recoverable claims, atomically publish the report, and delete the blob only after successful persistence.

4. **MEDIUM — Windows clean exits leak slots; nonterminal operation has no retention sweep.** [handler.rs:1033](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/handler.rs:1033), [main.rs:2060](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-pager-bin/src/main.rs:2060)  
   Windows `release_slot()` has no production caller or exit registration. Every ordinary Windows run leaves an empty file. With redirected stderr, startup skips the only sweep, so these files—and crash blobs on every platform—accumulate without a bound. **Fix:** wire Windows normal-exit cleanup, including explicit exit paths, and separate bounded maintenance from interactive notification.

5. **MEDIUM — Symbolication applies the wrong instruction adjustment.** [symbolicate.rs:115](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/symbolicate.rs:115)  
   Locked dependency `backtrace 0.3.76` already subtracts one inside `ResolveWhat::address_or_ip`. Return addresses therefore resolve at `RA − 2`; the faulting PC resolves at `PC − 1`. At a function or source-line boundary, the report can identify the preceding location. Existing marker tests check function names away from such boundaries. **Fix:** account for the dependency’s adjustment exactly once, compensate for the actual fault PC, and test boundary addresses and line numbers.

6. **MEDIUM — Unknown build identities can pass the same-build gate.** [symbolicate.rs:67](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/symbolicate.rs:67)  
   Two binaries without build IDs both carry zeros. Equal version, image span, and executable length then authorize symbolication even when their code differs; unknown executable lengths weaken this further. **Fix:** require a verified identity, compute a reliable fallback fingerprint outside the handler, or retain raw offsets when identity is unavailable. Add an equal-sized, unknown-identity negative case.

7. **MEDIUM — The scan limit can indefinitely starve dead slots.** [lib.rs:226](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/lib.rs:226)  
   Sorting and truncating happen before owner checks. If the first 256 names belong to live sessions or protected claims, every startup revisits them and never reaches later dead slots. Collecting the entire directory also leaves memory consumption unbounded despite the scan limit. **Fix:** use a bounded, fair traversal with continuation, or budget eligible work without permanently excluding later entries.

8. **MEDIUM — Claim recovery loses the PID-reuse guard.** [lib.rs:268](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/lib.rs:268)  
   Claims encode only the reader PID and check `owner_state(claimer, 0)`. If a reader dies and its PID is reused, the abandoned claim is treated as live for the replacement process’s lifetime. The existing recovery test only covers an unreused PID. **Fix:** include and verify the claimer’s start token, just as for writer slots.

9. **MEDIUM — Concurrent benign panics can produce a false crash notice.** [panic_info.rs:83](/Volumes/Mando/WaylandBots/Fuigo/wt-p05a/crates/codegen/fuigo-crash-handler/src/panic_info.rs:83)  
   Thread A can record a broken-pipe panic and pause in the chained hook. Thread B then encounters another benign panic, cannot record because the global slot is occupied, and aborts first. Its thread ID does not match A’s snapshot, so the handler records a raw signal and startup announces a crash. **Fix:** retain independently published per-thread panic classifications using signal-safe storage, and add a synchronized two-thread abort test.

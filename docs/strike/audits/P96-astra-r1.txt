3. **HIGH — Backup publication does not enforce “first copy wins.”**  
   [load_repair.rs:44](/Volumes/Mando/WaylandBots/Fuigo/wt-p96/crates/codegen/fuigo-shell/src/session/storage/jsonl/load_repair.rs:44)  
   The existence check, copy, and rename are separate operations, using one shared staging filename. On macOS/Linux, the final rename can replace an existing backup. Concrete interleaving: loader A observes no backup and pauses; loader B publishes the original backup and rewrites history; A resumes, copies the repaired file, and replaces B’s original backup. The first preserved copy is lost.  
   **Existing tests:** Do not catch it. `an_existing_backup_is_never_overwritten` only covers a backup already present before the check.

3. **HIGH — Remote campaign settings are incorrectly classified as explicit user choices.**  
   [config/mod.rs:602](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/config/mod.rs:602), [util/config/campaigns.rs:280](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/util/config/campaigns.rs:280)

   A remote settings campaign can set `models.image_description` or `models.session_summary`. Campaign patches are merged into effective TOML before `ModelOverrideConfig::resolve` receives it. That resolver labels every helper value in this table as explicit. Consequently, a remote campaign selecting a paid catalog helper bypasses subscription-default replacement, even when the user never configured that helper.

   **Tests miss it:** `model_overrides_record_which_helpers_the_user_chose` checks direct remote fields, but never passes campaign-merged effective configuration. Preserve source provenance through campaign merging.

5. **MEDIUM — Malformed HTTP requests can still complete or abort login.**  
   [subscription/flow.rs:431](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/auth/subscription/flow.rs:431)

   The parser checks only the first two whitespace-separated request-line tokens. It never validates the HTTP version, trailing tokens, or header syntax. For example, `GET /callback?state=S&code=x\r\n\r\n`, where `S` is the attempt’s state, lacks an HTTP version but starts exchange. With `error=access_denied` instead, it aborts login. F2 requires malformed requests to be ignored.

   **Tests miss it:** malformed fixtures omit a usable target/state; none combines the correct state with a malformed request line or headers.

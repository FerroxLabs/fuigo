   With the key saved only in `auth.json`, configure an MCP header as `"X-Template": "$${FUIGO_API_KEY}"`. The existing config expander consumes `$$` as a literal-dollar escape, producing `${FUIGO_API_KEY}`. The new destination resolver then interprets that literal as a credential reference and sends the saved key.

   This defeats the existing escape semantics and the requirement that an explicit reference constitutes consent. The destination receives a credential where the user requested literal text. Checking for `$$` only inside the late resolver would be insufficient: loading has already removed the escape.

The new resolver and conformance tests omit escaped key references. Preserve reference/escape provenance through loading and test the complete load-to-destination path.

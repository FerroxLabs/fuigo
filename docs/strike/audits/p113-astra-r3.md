3. **HIGH — Invalid UTF-8 disables archive shape protection.** [feedback_archive.rs:276](/Volumes/Mando/WaylandBots/Fuigo/wt-p113/crates/codegen/fuigo-shell/src/upload/feedback_archive.rs:276), [line 306](/Volumes/Mando/WaylandBots/Fuigo/wt-p113/crates/codegen/fuigo-shell/src/upload/feedback_archive.rs:306)

Additionally, any invalid byte anywhere in a file disables its whole-file PEM pass at line 249. **Coverage:** all new shape fixtures and decoded output arrays are valid UTF-8.

6. **HIGH — A torn PEM block can upload the complete private-key body.** [sanitizer.rs:27](/Volumes/Mando/WaylandBots/Fuigo/wt-p113/crates/codegen/fuigo-secrets/src/sanitizer.rs:27), [feedback_archive.rs:249](/Volumes/Mando/WaylandBots/Fuigo/wt-p113/crates/codegen/fuigo-shell/src/upload/feedback_archive.rs:249)

7. **MEDIUM — The whole-file PEM pass can splice together unrelated JSONL records.** [feedback_archive.rs:249](/Volumes/Mando/WaylandBots/Fuigo/wt-p113/crates/codegen/fuigo-shell/src/upload/feedback_archive.rs:249)  
   After scrubbing individual records, the code applies a multiline regex to every file, including JSONL. Different nesting depths in the opening and closing records produce invalid JSON; equal depths can silently collapse multiple records into one. **Coverage:** multiline PEM coverage uses a plain log only, not markers distributed across JSON records.

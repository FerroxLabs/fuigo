1. **HIGH — Round 2 #2 still does not preserve provenance from the same read.**  
   [campaigns.rs:303](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/util/config/campaigns.rs:303)

   The registry identifies a read by its **effective TOML value**, then replaces any existing entry with that value. Different provenance can produce identical effective TOML: read A explicitly sets `image_description = "local-helper"`; read B lacks that choice, but a campaign supplies the same value. Remembering B overwrites A’s provenance. Resolving retained A then classifies its explicit helper as Default and substitutes the subscription.

   Separately, eight subsequent distinct snapshots evict A entirely. A lookup miss silently removes explicit provenance through `resolve_with_user_config`, producing the same substitution.

   **Tests:** Not caught. The pairing test deliberately gives A and B different values, including different `p90_pairing_probe` values. It tests neither collisions nor eviction. Provenance needs to travel with the snapshot, rather than be recovered from this global cache.

2. **HIGH — An explicit helper missing from the catalog still falls through to a paid gateway.**  
   [agent/config.rs:5656](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/agent/config.rs:5656)

   Scenario: `image_description = "private-vision"` remains configured, but its local catalog entry disappears during reload. An unrelated `FUIGO_API_KEY` or deployment key remains available. The explicit-route protection only runs inside `if let Some(entry)`. With no entry, the resolver manufactures a gateway route using that key and returns `Some`.

   Consequently, the image refusal check does not fire, and Explicit prevents subscription substitution. Images go to the gateway—even if it subsequently rejects the unknown model. This is distinct from the deliberate session fallback discussed in Round 2 #3.

   **Tests:** Not caught. The keyless regression supplies a catalog entry. The unusable-image test passes `None` directly to the refusal predicate; it never exercises the resolver that converts this failure into `Some(gateway_config)`.

4. **MEDIUM — Malformed request targets can still terminate or complete login.**  
   [flow.rs:406](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/auth/subscription/flow.rs:406), [flow.rs:463](/Volumes/Mando/WaylandBots/Fuigo/wt-p90/crates/codegen/fuigo-shell/src/auth/subscription/flow.rs:463)

   For xAI, send this complete head, replacing `S` with the attempt’s state:

   ```text
   GET /callback?state=S&error=access_denied#junk HTTP/1.1\r\nHost: localhost\r\n\r\n
   ```

   The target check accepts `#`; URL parsing separates the fragment, leaving the matching state and error. Login aborts instead of ignoring the malformed request. Replacing the error with a code starts exchange. HTTP origin-form contains path and optional query, not a fragment. [RFC 9112 §3.2.1](https://datatracker.ietf.org/doc/html/rfc9112#section-3.2.1)

   **Tests:** Not caught. The malformed-head cases cover methods, versions, spacing and header syntax, but not malformed target characters. This is an F2 correctness failure, not a state-authentication bypass.

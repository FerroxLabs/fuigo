Two defects remain in `a84e3234..faad5ce7`. This was a read-only source audit; no Cargo commands or tests were run, and the worktree remains clean.

1. **HIGH — Escaped hook modifier forms still receive the saved key.**  
   [credential_env.rs:119](/Volumes/Mando/WaylandBots/Fuigo/wt-p70a/crates/codegen/fuigo-config/src/credential_env.rs:119), [env_expand.rs:69](/Volumes/Mando/WaylandBots/Fuigo/wt-p70a/crates/codegen/fuigo-hooks/src/env_expand.rs:69).

   The mask recognizes only plain references, whereas hook detection also recognizes modifier, length and indirection forms. For example:
   ```toml
   command = 'printf "%s" "$${FUIGO_API_KEY:-fallback}"'
   ```
   The mask declines this input. The parser’s `shellexpand` pass collapses `$$`, producing `${FUIGO_API_KEY:-fallback}`. The runner then detects consent, injects the saved key into the child environment, and the shell prints it. The configured escaped reference therefore discloses the key.

   **Existing tests do not catch this.** Parser/runner tests cover escaped plain references. The detector test checks `$${#FUIGO_API_KEY}` directly, bypassing the parser that changes it. This leaves F0c/F0d incomplete.

2. **MEDIUM — A fixed-marker collision disables escape protection.**  
   [credential_env.rs:109](/Volumes/Mando/WaylandBots/Fuigo/wt-p70a/crates/codegen/fuigo-config/src/credential_env.rs:109).

   If an input contains `ESCAPED_DOLLAR_MASK`, masking returns `None` and normal expansion proceeds. A concrete MCP configuration is:
   ```toml
   env = { TOKEN = "\uF8FFP70A_KEPT_DOLLAR\uF8FF $${FUIGO_API_KEY}" }
   ```
   After TOML decoding, the marker disables masking. Loading turns the escaped reference into `${FUIGO_API_KEY}`, and spawn-time resolution supplies the saved key despite the reference being escaped. Collision handling must preserve escaping rather than fall back to ordinary expansion.

   **Existing tests do not catch this.** The new escape tests contain no marker collisions; existing hook sentinel tests concern a different marker.

The inspected source otherwise supports resolver precedence, runtime-key exclusion, catalogue/cache credential restrictions, and the `getApiKey` premise. The Murage test launches a real agent binary, but its passing scenarios would not detect either defect above.

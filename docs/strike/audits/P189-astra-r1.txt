The new defects and regressions are:

1. **BLOCKER — SIGKILL does not establish process ownership.**  
   The reaper accepts a matching, predictable environment variable as sole ownership evidence, then signals a numeric PID. An independently launched process carrying that value—or an orphan carrying a previous Fuigo instance’s reused PID—qualifies. There is also a check-to-kill PID-reuse race: the inspected process can exit and its PID identify another process before `kill`. This violates the explicit “never kill an unrelated process” requirement. See [tool_reaper.rs:35](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/tool_reaper.rs:35) and [tool_reaper.rs:76](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/tool_reaper.rs:76). Linux documents PID reuse and stable process references through [pidfd_open](https://man7.org/linux/man-pages/man2/pidfd_open.2.html).

2. **HIGH — Stop reports success without proving all tool processes dead.**  
   With two resident sessions, the sweep is simply omitted. On macOS/Windows it returns an empty list. Linux `/proc` enumeration/read failures also become absence; marker-cleared `setsid` descendants remain invisible. A detached survivor whose tracked parent task has ended therefore permits `parked:true`. The receipt documents some limitations, but they contradict R4 rather than satisfy it. Evidence: [tool_reaper.rs:29](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/tool_reaper.rs:29), [tool_reaper.rs:45](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/tool_reaper.rs:45), [session_park.rs:282](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:282).

3. **HIGH — ACP terminal task listing creates a circular wait.**  
   Park calls `complete_park`, then `running_task_ids`. The ACP terminal backend lists tasks by sending `terminal/output`, which `ParkHoldClient` now holds until unpark. Park cannot finish until that request finishes. Even a completed but still tracked terminal causes the request. No timeout surrounds this post-transition wait. Evidence: [session_park.rs:294](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:294), [adapter.rs:614](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell-terminal/src/adapter.rs:614), [adapter.rs:330](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell-terminal/src/adapter.rs:330), [park_hold.rs:380](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:380).

4. **HIGH — Park transitions lack operation identity and publish success eligibility too early.**  
   A second park sees `Parked` while the first stop is still reaping and can return `alreadyParked:true` before death confirmation or process-wide hold activation. Separately, an old park distinguishes withdrawal only by whether *some* entry exists. Unpark followed by another park lets the old operation complete or withdraw the new operation’s entry. An ongoing reaper also continues after withdrawal and can kill tools launched by the newly admitted prompt. Evidence: [session_park.rs:225](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:225), [session_park.rs:262](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:262), [quiesce.rs:166](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/quiesce.rs:166).

5. **HIGH — Model gates do not cover admission through submission.**  
   Concrete sequence: a background subagent passes `wait_model_allowed`, blocks on a saturated sampling semaphore, its root parks, then another request releases a permit. The subagent submits without checking the park again. Side-call preparation likewise checks before subsequent asynchronous preparation and eventual dispatch. Evidence: [sampler_turn.rs:2105](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_session_impl/sampler_turn.rs:2105), [sampler_turn.rs:2123](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_session_impl/sampler_turn.rs:2123), [sampler_turn.rs:1206](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_session_impl/sampler_turn.rs:1206).

6. **HIGH — MCP reverse traffic escapes the parked connection.**  
   `_fuigo/mcp/sdk_call` contains `{serverId,message}`, not `sessionId`. `wait_request_allowed(None)` immediately permits transmission, regardless of `parked_here`. A parked load reconnecting an ACP-backed MCP server can therefore write reverse requests, violating both R3 and R8. Evidence: [acp_mcp.rs:70](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_mcp.rs:70), [park_hold.rs:285](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:285).

7. **HIGH — Scheduler pause and overdue folding can fail silently.**  
   A scheduler already inside a slow fire cannot process `SetPaused`; the handler discards the five-second acknowledgement timeout and continues parking. Existing fire processing includes waits longer than five seconds. On implicit resume, overdue durable one-shots deliberately run normally, and a timed-out fold acknowledgement can lose the reminder after tasks were advanced or removed. Evidence: [session_park.rs:168](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:168), [scheduler/actor.rs:486](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-tools/src/implementations/fuigo_build/scheduler/actor.rs:486), [scheduler/actor.rs:860](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-tools/src/implementations/fuigo_build/scheduler/actor.rs:860).

8. **HIGH — Implicit unpark opens execution before admitting the user’s prompt.**  
   The registry entry is removed, then the handler awaits scheduler resume. During that gap, a completion notification can invoke the now-enabled drain and start an autonomous turn. `kick:false` only suppresses the explicit release command’s kick; it does not suppress other actor events. Old permission/question requests waiting in the gateway can also reach the wrapper after removal and escape cancellation. Evidence: [session_park.rs:425](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:425), [run_loop.rs:1036](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_session_impl/run_loop.rs:1036), [acp_agent.rs:1088](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/mvp_agent/acp_agent.rs:1088).

9. **HIGH — Teardown loses hold ownership and leaves stale connection state.**  
   Dropping a child’s `SessionGuard` removes its parent link. Held child frames and requests then appear unparked even while the root remains parked; request waiters can send on this teardown wakeup. Closing the parked root removes its registry entry but never removes `parked_here`, so process-wide notifications remain held indefinitely on the warm connection. Later clients/sessions that never park can inherit that suppression. Evidence: [quiesce.rs:294](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/quiesce.rs:294), [park_hold.rs:145](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:145), [park_hold.rs:293](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:293).

10. **HIGH — Advertised deadlines do not bound the awaited operations.**  
    Park’s probe, task listing and task killing await actor replies without deadline wrappers. Its deadline starts after scheduler pause and initial kills. Parked-load readiness similarly checks its deadline only *after* an unbounded status reply. Thus these paths can hang rather than return their promised bounded outcome. Evidence: [session_park.rs:122](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:122), [session_park.rs:254](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:254), [session_park.rs:383](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:383).

11. **MEDIUM — Released filesystem/terminal requests are unmarked.**  
    These methods distinguish cancellation from sending but discard the `released` flag. Explicit unpark therefore emits old requests without `fuigo/released:true`. Permission requests correctly preserve it. Evidence: [park_hold.rs:347](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:347).

12. **LOW — Cancellation-generation entries accumulate permanently.**  
    Every implicitly unparked session adds an entry; no close or release path removes it. The notification cap also does not cap independently spawned held-request futures. Evidence: [park_hold.rs:266](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:266), [gateway.rs:151](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-acp-lib/src/gateway.rs:151).

13. **LOW — Tool environments change even for clients that never park.**  
    `FUIGO_AGENT_PID` is now forcibly added/overwritten for every tool terminal. Both the supplied base and the v1.0.21 source reference only forced `FUIGO_AGENT`. This is an observable compatibility change under the stated strict “unchanged” requirement. Evidence: [env.rs:48](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-tools/src/util/env.rs:48).

The straight-line hold-check/enqueue/ack ordering on one `LocalSet` is sound: the ACP notification enqueue is synchronous. The failures above arise from uncovered requests, asynchronous state transitions, actor admission and lifetime handling.

The added tests cover useful happy paths, but not these transition failures. In particular, the stop test discovers survivors using the same environment-marker predicate as production, so it cannot detect marker-cleared survivors. I found no further confirmed standalone no-park functional regression; runtime compatibility remains unverified.

Evidence: [session_park.rs:425](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:425), [run_loop.rs:1036](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/acp_session_impl/run_loop.rs:1036), [acp_agent.rs:1088](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/mvp_agent/acp_agent.rs:1088).

9. **HIGH — Teardown loses hold ownership and leaves stale connection state.**  
   Dropping a child’s `SessionGuard` removes its parent link. Held child frames and requests then appear unparked even while the root remains parked; request waiters can send on this teardown wakeup. Closing the parked root removes its registry entry but never removes `parked_here`, so process-wide notifications remain held indefinitely on the warm connection. Later clients/sessions that never park can inherit that suppression. Evidence: [quiesce.rs:294](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/session/quiesce.rs:294), [park_hold.rs:145](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:145), [park_hold.rs:293](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:293).

10. **HIGH — Advertised deadlines do not bound the awaited operations.**  
    Park’s probe, task listing and task killing await actor replies without deadline wrappers. Its deadline starts after scheduler pause and initial kills. Parked-load readiness similarly checks its deadline only *after* an unbounded status reply. Thus these paths can hang rather than return their promised bounded outcome. Evidence: [session_park.rs:122](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:122), [session_park.rs:254](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:254), [session_park.rs:383](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/extensions/session_park.rs:383).

11. **MEDIUM — Released filesystem/terminal requests are unmarked.**  
    These methods distinguish cancellation from sending but discard the `released` flag. Explicit unpark therefore emits old requests without `fuigo/released:true`. Permission requests correctly preserve it. Evidence: [park_hold.rs:347](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:347).

12. **LOW — Cancellation-generation entries accumulate permanently.**  
    Every implicitly unparked session adds an entry; no close or release path removes it. The notification cap also does not cap independently spawned held-request futures. Evidence: [park_hold.rs:266](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-shell/src/agent/park_hold.rs:266), [gateway.rs:151](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-acp-lib/src/gateway.rs:151).

13. **LOW — Tool environments change even for clients that never park.**  
    `FUIGO_AGENT_PID` is now forcibly added/overwritten for every tool terminal. Both the supplied base and the v1.0.21 source reference only forced `FUIGO_AGENT`. This is an observable compatibility change under the stated strict “unchanged” requirement. Evidence: [env.rs:48](/Volumes/Mando/WaylandBots/Fuigo/wt-p189/crates/codegen/fuigo-tools/src/util/env.rs:48).

The straight-line hold-check/enqueue/ack ordering on one `LocalSet` is sound: the ACP notification enqueue is synchronous. The failures above arise from uncovered requests, asynchronous state transitions, actor admission and lifetime handling.

The added tests cover useful happy paths, but not these transition failures. In particular, the stop test discovers survivors using the same environment-marker predicate as production, so it cannot detect marker-cleared survivors. I found no further confirmed standalone no-park functional regression; runtime compatibility remains unverified.

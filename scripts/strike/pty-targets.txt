# The ignored PTY suite: what `final-gate.sh --pty` (and so release-gate.sh) runs, each as `cargo test ... -- --ignored`.
#
# These tests spawn the real pager binary in a pseudo-terminal and are marked #[ignore], so a plain `cargo test` (the default
# gate) never runs them. They need the built pager binary; the gate builds it and passes it as PAGER_BINARY.
#
# Line format:  <package> <test|lib|tests> <target|-> <threads> [name-filter]
#   test   one integration-test target (`--test <target>`)
#   lib    the package's unit-test binary; the optional name filter restricts it (the lib also holds ignored tests that are not
#          terminal tests, e.g. a child-process helper that only means something when its parent test launches it)
#   tests  every test target of the package (lib, bins and integration tests)
#   <threads> is --test-threads for that invocation. leader_pty_e2e and the in-process leader cluster run one at a time: each test starts a
#   leader and several clients, and two of them at once starve each other.
#
# Every `#[ignore]` terminal test in the tree has to be reachable from here. After adding a test target with ignored tests, add it below;
# gate-selftest.sh checks that every `test` line names a target that exists.

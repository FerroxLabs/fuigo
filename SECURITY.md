# Security Policy

Fuigo is maintained by Ferrox Labs. Please report security vulnerabilities privately by email to
**Sean@ferroxlabs.com** with "Fuigo security" in the subject.

Include the Fuigo version (`fuigo --version`), your platform, and the steps or input that reproduce the problem.
We will reply to confirm receipt and keep you informed until a fix ships.

Do not open public GitHub issues or pull requests for security reports.

Fixes are released in the latest version on npm (`npm install -g fuigo@latest`); older versions do not receive
separate security patches.
